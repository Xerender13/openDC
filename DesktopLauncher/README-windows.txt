openDC Launcher (Windows 10 and 11)

1. Extract this whole folder anywhere (for example C:\Games\openDC Launcher). Don't run it from inside the zip.
2. Open "openDC Launcher.exe". If Windows shows "Windows protected your PC", click "More info" and then
   "Run anyway" (the program has no paid code signature).
3. Click DOWNLOAD, pick the client (2016 recommended) and the folder. The launcher downloads the game (Google Drive),
   the openDC server (GitHub), Python and PostgreSQL and installs everything. No Docker needed.
4. Press PLAY. Closing the launcher closes the game, the server and the database.

Already have openDC in a folder? In the install window click "I already have openDC in a folder" and pick the
folder that has Emulator in it.

Launcher settings: %APPDATA%\openDC Launcher. Logs: <openDC folder>\runtime\logs.
Windows 7 and 8.1 are not supported (Electron needs Windows 10 or newer).
